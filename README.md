
# Beauté Studio – Luxury Beauty & Skincare Website

## About the Project

Beauté Studio is a luxury beauty and skincare website designed to showcase beauty products, skincare collections, makeup and beauty services.

The website focuses on elegance, simplicity and a modern design to provide visitors with an attractive and user-friendly browsing experience.

## Features

- Elegant homepage and navigation menu
- Luxury beauty and skincare collection
- Featured skincare product section
- Beauty services and treatments
- Beauty brand story section
- Contact information and social media links
- Responsive navigation for mobile devices
- Interactive animations and visual effects

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive features and animations

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the website using a browser or the Live Server extension in VS Code.
